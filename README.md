### Текст задачи

- за какие партии проголосовали граждане из каждой группы;

5. Подсчитать, в скольких группах встречается каждая партия.
6. Вывести партии, за которые проголосовали граждане только одной группы.

## Задача 5

### Текст задачи

После единых выпускных экзаменов по информатике в район пришла информация о том, какой ученик какой школы сколько баллов набрал. По положению об экзамене каждый район сам определяет, за какой балл нужно поставить какую оценку.

Районный методист решила, что оценку «отлично» должны получить 20% участников (целое число, с отбрасыванием дробной части). Для этого она должна определить, какой балл должен был набрать ученик, чтобы получить «отлично». Если невозможно определить такой балл, чтобы «отлично» получили ровно 20% участников, «отлично» должно получить меньше участников, чем 20%. Если таких участников не окажется (наибольший балл набрали больше 20% участников) — эти и только эти ученики должны получить «отлично».

Напишите программу, которая должна вывести на экран наименьший балл, который набрали участники, получившие «отлично». Известно, что информатику сдавало больше 5-ти учеников. Также известно, что есть такое количество баллов, которое не получил ни один участник.

На вход программе сначала подаётся число учеников, сдававших экзамен. В каждой из следующих N строк находится информация об учениках в формате:

<Фамилия><Имя><Номер школы><Количество баллов>

где <Фамилия> — строка, состоящая не более чем из 30 символов без пробелов, <Имя> — строка, состоящая не более, чем из 20 символов без пробелов, <Номер школы> — целое число в диапазоне от 1 до 99, <Количество баллов> — целое число в диапазоне от 1 до 100. Эти данные записаны через пробел, причём ровно один между каждой парой (то есть, всего по три пробела в каждой строке).

Пример входной строки:

Иванов Иван 50 87

Пример выходных данных:

78

### Алгоритм решения

1. Сформировать текстовый файл с данными об учениках.
2. Считать количество учеников и сведения о каждом из них.
3. Подсчитать количество участников, набравших каждый балл, используя словарь.
4. Определить количество участников, которые должны получить оценку «отлично»: 20% от общего количества с отбрасыванием дробной части.
5. Рассматривать набранные баллы в порядке убывания.
6. Учесть, что участники с одинаковым баллом должны получать одинаковую оценку.
7. Определить наименьший балл среди участников, получивших оценку «отлично».
8. Вывести найденный балл.

## Задача 7

### Текст задачи

Унарные операции:

! — установить соответствующую координату в 0, чтобы получился правильный диапазон. Ответом должен быть объект LineSegment.

Операции приведения типа:


int (неявная) — результатом является целая часть координаты y;

double (явная) — результатом является координата x.

Бинарные операции:

+ LineSegment целое число (левосторонняя операция, увеличивается координата x, ответом должен быть правильный диапазон);

+ целое число LineSegment (правосторонняя операция, увеличивается координата y, ответом должен быть правильный диапазон);

> LineSegment d — результат равен true, если левый диапазон включает правый, и false — в противном случае.

### Алгоритм решения

1. Перегрузить унарный оператор ! для получения правильного диапазона.
2. Реализовать неявное преобразование типа LineSegment в int, возвращающее целую часть координаты y.
3. Реализовать явное преобразование типа LineSegment в double, возвращающее координату x.
4. Перегрузить оператор + для увеличения координаты x на целое число.
5. Перегрузить оператор + для увеличения координаты y на целое число.
6. После изменения координат обеспечить получение правильного диапазона.
7. Перегрузить оператор > для проверки включения правого диапазона в левый.
8. Проверить работу всех перегруженных операций.
